# MP3 파일 이름 번역 — asmr_cover_embed.sh --export-names / --rename-map

일본어·중국어로 된 MP3 **파일 이름**을 번역표대로 바꾼다. 폴더 이름과 태그는 건드리지 않는다.

## 순서

1. 번역할 이름 목록을 만든다.

   ```bash
   bash ~/asmr_cover_embed.sh --export-names
   ```

   가나나 한자가 있고 **한글이 한 글자도 없는** MP3 이름이 `Download/mp3_names_ja.txt`에 작품별로 저장된다.
   이미 한국어인 이름은 건너뛰고, 같은 이름(SE 있음/없음 폴더 등)은 한 번만 적는다.
2. 목록을 번역해 `원래 이름<TAB>새 이름` 형식의 번역표(`.tsv`)를 만든다. 확장자는 적지 않아도 된다.
3. 미리보기로 바뀔 이름을 확인한다.

   ```bash
   bash ~/asmr_cover_embed.sh --reuse-scan --rename-map ~/storage/downloads/번역표.tsv
   ```
4. 같은 명령에 `--apply`를 붙여 적용한다.

휴대폰 폴더라면 `--local-dir ~/storage/downloads/Moving`을 붙인다.

## 규칙

- `\ / : * ? " < > |`는 전각 문자(`＼ ／ ： ＊ ？ ＂ ＜ ＞ ｜`)로 바꾼다. 250바이트를 넘는 이름은 거부한다.
- 같은 폴더에 바꿀 이름의 파일이 이미 있으면 바꾸지 않는다 (충돌).
  단, 두 파일의 내용이 바이트 단위로 같으면 중단된 이전 작업으로 보고 원래 이름 쪽을 지운다.
- SD 카드(SAF)에는 이름 바꾸기 명령이 없다. 그래서 새 이름으로 복사하고, 다시 읽어 SHA-256으로 확인한 뒤 원본을 지운다.
  확인 전에는 원본을 지우지 않으므로 중간에 끊겨도 곡이 사라지지 않는다.
  곡마다 읽기·쓰기를 하므로 시간이 걸린다.
- `--local-dir` 폴더는 그냥 이름만 바꾼다.
