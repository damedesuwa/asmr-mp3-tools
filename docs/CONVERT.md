# snow_convert_final_v3.sh

이 스크립트는 휴대폰 폴더(기본: `~/storage/downloads/Moving`) 안의 오디오를 **MP3 320 kbps CBR / 44,100 Hz / Stereo**로 통일한다.
변환이 끝나면 이어서 작품별 썸네일(240×240 Front Cover)까지 넣는다.

## 설치 (Termux)

```bash
pkg install python ffmpeg termux-api
pip install mutagen
termux-setup-storage
```

같은 폴더(예: `~`)에 다음 파일 세 개를 둔다.

- `snow_convert_final_v3.sh`: 변환
- `asmr_cover_update.sh`: 썸네일 단계 실행기
- `asmr_cover_embed.sh`: 썸네일 본체

## 실행

| 명령어 | 기능 |
|---|---|
| `bash ~/snow_convert_final_v3.sh` | 미리보기 (변환·삭제 없음) |
| `bash ~/snow_convert_final_v3.sh --dry-run` | 미리보기 |
| `bash ~/snow_convert_final_v3.sh --apply` | 실제 변환 후 썸네일 적용 |
| `bash ~/snow_convert_final_v3.sh --help` | 도움말 |

추가 옵션은 두 가지다.

- `--dir 경로`: 다른 폴더를 처리한다.
- `--no-cover`: 썸네일 단계를 건너뛴다.

## 대상

- 하위 폴더까지 재귀적으로 검색한다.
- 확장자: `.mp3 .wav .flac .m4a .aac .ogg .opus .wma .aiff .aif .mp4`
  - `.mp4`는 영상을 버리고 첫 번째 오디오 스트림만 쓴다.
- 이름에 `.snow_v2_` 또는 `.snow_v3_`가 들어간 임시·백업 파일은 제외한다.

## 처리 규칙

| 상황 | 처리 |
|---|---|
| MP3가 아닌 파일 | 같은 폴더에 `이름.mp3`로 변환하고, 최종 위치에서 재검증을 통과하면 원본을 삭제 |
| 같은 이름의 `.mp3`가 이미 있음 | 덮어쓰지 않음 (이름 충돌) |
| 이미 320 kbps / 44.1 kHz / Stereo인 MP3 | 그대로 둠 |
| 규격이 다른 MP3 | 재인코딩. 교체하는 동안만 원본을 `이름.mp3.snow_v3_backup_날짜_시간_PID`로 옮겨 두고, 새 파일이 재검증을 통과하면 백업을 삭제 |
| 오디오를 읽을 수 없는 파일 | 실패로 기록하고 원본 보존 |

출력에는 LAME 인코더를 쓴다. 메타데이터, 챕터, 커버를 모두 지우고 오디오만 남긴다.
커버는 다음 썸네일 단계에서 다시 넣는다.

## 검증과 원본 보호

1. 같은 폴더에 숨김 임시 파일(`.snow_v3_tmp_…mp3`)을 먼저 만든다.
2. 임시 파일을 검사한다. 검사 항목은 다음과 같다.
   - 파일 존재
   - 0바이트가 아님
   - MP3 코덱
   - 320 kbps, 44,100 Hz, 2채널
   - 재생 시간 > 0
3. 앞 3초를 디코딩하고, 끝에서 5초 지점부터 3초를 디코딩한다.
4. 통과하면 `mv -n`으로 최종 이름에 옮긴다. 기존 파일은 덮어쓰지 않는다. 옮긴 뒤 크기가 맞는지 확인한다.
5. 최종 위치의 파일을 같은 항목으로 한 번 더 검증한다.
6. 재검증을 통과한 뒤에만 원본(MP3 재인코딩이면 그 백업)을 삭제한다. 재검증에 실패하면 새 파일을 지우고 원본을 원래 이름으로 되돌린다.

Ctrl+C로 중단하면 다음과 같이 처리한다.

- 임시 파일을 지운다.
- 처리 중이던 원본은 지우지 않는다.
- MP3 교체 도중이었다면 백업을 원래 이름으로 되돌린다.

**한계:** 파일 전체를 처음부터 끝까지 디코딩하지는 않는다. 그래서 중간 부분의 손상까지 완벽히 잡지는 못한다.

## 썸네일 단계 (변환 뒤 자동)

검색 위치 바로 아래 폴더 하나를 작품 하나로 본다.

- 작품 안 이미지(JPG/PNG/WEBP…)가 1장이면, 그 작품의 커버 없는 MP3 전부에 240×240 Front Cover를 넣는다.
- 이미지가 없거나 여러 장인 작품은 넣지 않고 알려 준다.
- 미리보기 모드에서는 썸네일도 미리보기만 한다. 아직 MP3로 바뀌지 않은 파일은 실제 변환 뒤에 썸네일 대상이 된다.

## 진행률 표시

```
  전체 작업  33% | 파일 3 / 9 | 현재 파일  85% | 경과 시간 02:15
```

파일마다 변환 완료, 검증 통과, 완료 또는 실패가 표시된다.
마지막에 다음 통계가 나온다.

- 전체 대상
- 변환 완료
- 건너뜀
- 이름 충돌
- 실패
